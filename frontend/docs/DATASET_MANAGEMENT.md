## 1. Overview & Purpose

The **TATTVA Dataset Management System** provides a unified registry and universal loader for all evaluation datasets used across TATTVA AI. It abstracts differences in file formats (`CSV`, `JSON`, `JSONL`, `Parquet`), handles character encodings (including UTF-8 BOM stripping and Indic Unicode canonical NFC normalization), validates schemas against strict rules, and enforces dataset metadata governance and training/evaluation contamination boundaries.

## 3. Universal Loader & Schema Adapters

The registry loader (`app/lib/evaluation/datasets/dataset-registry.ts`) dynamically resolves file locations across monorepo root and frontend workspaces:

```typescript
import { datasetRegistry } from "@/lib/evaluation/datasets/dataset-registry";

// 1. List available datasets
const datasets = datasetRegistry.listDatasets();

// 2. Load questions with automatic format conversion
const records = datasetRegistry.loadRecords("mmmlu-hi-in-sample");
```

## 4. Unicode & Character Handling Guarantees

Indic scripts (Devanagari for Hindi, Telugu script `\u0C00-\u0C7F`) require explicit text normalization to prevent character corruption:

1. **UTF-8 Byte Order Mark (BOM) Stripping**:
   - Files generated by Windows Excel or exported text tools often prepend the 3-byte sequence `[0xEF, 0xBB, 0xBF]`.
   - The loader inspects the raw buffer header and strips the BOM bytes prior to UTF-8 decoding.

2. **NFC Normalization**:
   - All text content is normalized using Unicode Normalization Form C (`.normalize("NFC")`), ensuring that combining vowel signs (matras) and consonants are canonicalized uniformly.

3. **RFC-4180 Multi-line CSV Parsing**:
   - Utilizes a robust finite state machine parser (`mmmluValidator.parseRFC4180CSV()`) supporting embedded newlines, quotes, and Hindi commas without line splitting errors.

## 5. Security & Double-Blind Isolation

When client requests inspect datasets via the Dataset Library API (`GET /api/evaluation/datasets/[id]`):
- Ground-truth answers (`expectedAnswer`, `answer`) are **strictly masked** or omitted.
- Raw file paths on the host filesystem are redacted.
- Only schema shapes, sample questions without answers, and summary metadata are returned to dashboard consumers.
